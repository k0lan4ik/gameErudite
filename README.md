# gameErudite
### Как установить игру?
заходите в папку Installers, выбираете нужную вам версию установочного файла и скачиваете.
После скачивания и запуска установочного файла, необходимо выбрать путь до места, где будет установлена папка с необходимыми файлами, и нажать кнопку “next” (рис. 1). Затем необходимо выбрать имя папки со всем содержимым и начать установку, нажав кнопку “next”. Затем требуется подтвердить установку, нажав кнопку “install”. В случае удачной установки, необходимо завершить работу с установочным файлом, нажав кнопку “finish”

После установки игровой программы необходимо раскрыть папку, имя и путь до которой пользователь указывал при установки. Для запуска самой программы необходимо запустить файл с названием “Erudit”. После этого запуститься игровая программа “Эрудит”. Или же просто вбить в поиск "Erudit".
### Как играть
Правила стандартного эрудита:
У каждого игрока есть набор из 10 букв. Нужно по очереди составлять слова.
За правильно составленное слово игрок получает очки, количество которых равно длине составленного слова. Если ваше слово начинается с той же буквы на которую закончилось слово предыдущего игрока, то очки за составленное слово удвоятся. 
Если игрок неправильно ввели слово, то он потеряет очки равные длине неправильно составленного слова. Игрок может ничего не вводить, тогда он пропустит ход и не потеряет очки.
Победит игрок набравший наибольшее количество очков. Игра закончится когда все игроки пропустят ход.
У каждого игрока есть два бонуса: «50-на-50» и «помощь друга». «50-на-50» игрок выбирает пять букв которые хочет заменить, при этом он теряет 2 очка. 
«помощь друга» игрок может заменить «ненужную» ему букву на «понравившуюся» ему букву из набора букв соперника.
### Краткий гайд по интерфейсу
- Главное меню
  
  При запуске программы пользователь попадает в главное меню программы (рис. 3). Здесь пользователю предоставляется возможность начать новую игру, выбрав “Новая игра”, загрузить прошлую незавершенную игру, выбрав “Загрузить сохранение”, или ознакомиться с правилами игры, выбрав “Правила” на главном меню.

![image](https://github.com/user-attachments/assets/f6a8ff89-22fa-43e3-a585-80e84176dda6)

- Сохранения
  
  В данном разделе находятся все сохраненные незавершенные игры (рис. 4). Для того, чтобы завершить какую-либо из игр, необходимо выбрать прошлую незавершенную игру и запустить ее, нажав кнопку “Выбрать”. Для выхода из данного раздела и перехода на главное меню, нужно выбрать кнопку “Отмена”.

- Правила
  
  В данном разделе можно ознакомиться со всеми правилами игровой программы “Эрудит”

![image](https://github.com/user-attachments/assets/fa70a2e3-978a-44f3-a0d3-0e96a611b4ae)

- Начало и ход игры
  
  Для начала игры необходимо выбрать “Новая игра”. После откроется окно с выбором количества игроков (2 – 10 игроков) (рис. 6). После выбора необходимого количества игроков выбираем “Подтвердить”. Затем начнется игра, все игроки получат свои наборы из банка букв. Сперва будет открыто окно первого игрока (рис. 7). Пользователь может составлять слова, нажимая непосредственно по самим буквам в необходимом порядке. Для удаления отмены выбора буквы также необходимо нажать непосредственно на саму букву. Также пользователь может использовать какой-либо из бонусов (“Помощь друга”, ”50-на-50”), просто выбрав желаемый бонус. Для пропуска хода можно не выбирать буквы и выбрать “Подтвердить”. После каждого хода игрока, ему будет всплывать уведомление о том, что произошло за данный ход, и его количество текущих очков. После завершения игры появится уведомление о результатах игры.

- Бонус “Помощь друга”
  
  При выборе данного бонуса, пользователю открывается окно с выбором игрока и его набора букв (располагаются выше), и собственным набором букв (располагаются ниже) (рис. 8). Выбирать буквы можно уже ранее описанным способом. После выбора букв необходимо выбрать “Подтвердить”, пользователь вернется в главное меню, бонус будет использован и недоступен для использования в дальнейшем.

![image](https://github.com/user-attachments/assets/9ef381b1-93b2-4e2e-a683-da9209401ede)

- Бонус “50-на-50”
  
  При выборе данного бонуса, пользователю открывается окно с букв из собственного набора (рис.9). Выбирать буквы можно уже ранее описанным способом. После выбора необходимого количества букв, у пользователя появится возможность выбрать кнопку “Подтвердить”, нажав которую пользователь вернется в главное меню, бонус будет использован и недоступен для использования в дальнейшем.
